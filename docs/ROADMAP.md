# Roadmap

Everything below “Current” is future work and not a claim about implemented capability.

## Current

- Account/session flow with MongoDB.
- Check-in, capacity estimate, driver display, one-action recommendation, measurement, feedback, insights/history, privacy controls, and authenticated demo tools.
- SQLite product persistence by default; template explanation provider by default.

## Next (suggested)

- Rehearse moderated usability sessions and improve confusing steps.
- Add frontend/browser tests and API contract coverage for critical flows.
- Review privacy disclosures, consent semantics, data retention, and account lifecycle.
- Conduct security review of production session, CSRF, rate limit, secret, and deployment settings.
- Improve measurement methodology before making efficacy claims.
- Add operational health/readiness checks and durable database backups.

## Future (ideas, not commitments)

- Qualified clinical/safety advisor review of language, action library, and crisis handoff.
- Carefully designed real-user evaluation with appropriate review and consent.
- Optional integrations (calendar/wearables) only with explicit consent and minimization.
- Mobile client or improved installable experience.
- More robust experimentation and recommendation evaluation.
- Managed SQL/Mongo deployment, observability, scaling, and operational playbooks.
